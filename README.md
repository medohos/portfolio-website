# Personal Portfolio Website

My personal developer portfolio website. Built from scratch with pure HTML, CSS, and vanilla JavaScript without any external frameworks.

[Live Demo](https://medohos.github.io/portfolio-website/)

## Overview

Designed with a modern dark theme, glassmorphism UI elements, and cyan/purple gradients. Includes interactive background effects and smooth scroll animations.

## Highlights

- **Interactive Background**: Built using HTML5 Canvas API with animated particle nodes that react to mouse movement.
- **Glassmorphism UI**: Backdrop blur effects and translucent card layers using modern CSS properties.
- **Responsive Layout**: Designed using CSS Flexbox and Grid to look clean across mobile, tablet, and desktop viewports.
- **Performance**: Zero external UI library dependencies for lightweight loading and instant transitions.

## Tech Stack

- **Markup**: HTML5
- **Styling**: Vanilla CSS3 (Custom properties, Flexbox, Grid, CSS animations)
- **Scripting**: Modern JavaScript (ES6+, Canvas API, IntersectionObserver)

## Structure

```
├── index.html   # Main layout and semantic sections
├── style.css    # Design system, glassmorphism, responsive styles
└── script.js    # Interactive canvas particles and scroll reveal logic
```
